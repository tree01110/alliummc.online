Download Allium.

Allium uses Prism Launcher exclusively.

We use Prism instead of CurseForge or Modrinth because it's lightweight and open source. This enables us to circumvent licensing issues and maximize performance on low-end systems. Prism will also automatically update the pack whenever you open it.

STEP 01

Install Prism Launcher

Open the official Prism Launcher website. Download Prism for your computer, install it normally, and open it.

Once the import finishes processing, double-click the new Allium instance to launch it. The modpack will install itself automatically.
