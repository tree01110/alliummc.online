Download Allium

Allium uses Prism Launcher, an open-source Minecraft launcher built around separate instances. You only have to import Allium once; after that, the instance checks for Allium updates whenever you open it.

Why Prism?
It gives Allium a consistent installation and lets us ship the exact configuration the server expects while keeping updates simple. Once the instance is installed, you launch Allium from Prism like any other Minecraft installation.
STEP 01

Download Prism

Go to the official Prism Launcher website, download the installer for your computer, install it, and open Prism.
